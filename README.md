# SIOM Nashik · S2C2 · Six Sigma Consulting Projects 2027

A slide-style web page for pitching Black Belt-level Lean Six Sigma (DMAIC / DMADV) projects to host companies, 18 January – 27 February 2027.

## Open it
- **On your laptop:** double-click `index.html`. It opens in any browser; no install needed.
- **On iPad or phone:** turn on GitHub Pages (repo **Settings → Pages → Deploy from branch → `main` / root**). The page will then be at `https://samriddha-basu-cloud.github.io/Six-Sigma-SIOM/`.

## Using the deck
- Next / previous: arrow buttons, ← → keys, or swipe on touch screens.
- **Contents** (top right) jumps to any slide; **Contact** jumps to the last slide.
- Each slide has its own link, e.g. `index.html#7` opens the project ideas.
- On the Project ideas slide, search or filter by area, tap an idea for details, and use "I'm interested" to send a pre-filled email.

## Slides
1. Welcome
2. Who we are
3. Why host us (the win-win)
4. Project requirements
5. How the 6 weeks run (DMAIC timeline)
6. Deliverables & certificate of completion
7. Project ideas (about 90, searchable, incl. services)
8. Past host companies
9. Team & contact (all six S2C2 members)

## Editing
Everything is in `index.html`:
- Project ideas: the `PROJECTS` list in the script.
- Past host companies: the `COMPANIES` list. `logo:` is a logo URL from the company's website; `d:` is its domain for a web-icon fallback. A file in `logos/` overrides both (see `logos/README.md`).
- Team: the `TEAM` list (name, email, phone).

## Logos
Logos load from files in `logos/` first, then from logo URLs on each company's website (when online), then the site's web icon, then initials. Logo files saved in `logos/` work offline too. See `logos/README.md` for file names.
